# 视频生成提示词模板

## 通用结构
```
[主体描述] + [动作/场景] + [镜头语言] + [风格] + [画质参数]
```

## 分类模板

### 1. 产品展示
```
A sleek [产品名] rotating on a minimalist pedestal, soft studio lighting, 
slow 360-degree orbit shot, 4K, photorealistic, shallow depth of field, 
cinematic color grading
```

### 2. 人物口播
```
A confident person speaking directly to camera, warm natural lighting, 
medium shot, subtle hand gestures, clean background, professional studio 
setup, 1080p, 24fps
```

### 3. 风景空镜
```
Breathtaking [地点] at golden hour, drone aerial shot slowly descending, 
mist rolling over mountains, sun rays breaking through clouds, epic 
cinematic wide angle, 8K, hyper-realistic
```

### 4. 科技感
```
Futuristic interface with floating holographic data, neon blue and purple 
glow, camera slowly pushing in, particles floating, cyberpunk aesthetic, 
4K, smooth 60fps motion
```

### 5. 美食
```
Close-up of [菜品] being served, steam rising, slow motion drizzle of 
sauce, warm appetizing lighting, macro lens, shallow depth of field, 
food photography style, 4K
```

## 负面提示词（Negative Prompt）
```
blurry, low quality, distorted, ugly, deformed, bad anatomy, extra limbs, 
watermark, text, signature, jittery, flickering
```

## 常用参数
- **时长**：5-10秒（短片段易控制）
- **分辨率**：1080p 起步，4K 更佳
- **帧率**：24fps（电影感）/ 30fps（流畅）/ 60fps（丝滑）
- **运镜**：固定 > 缓慢推拉 > 复杂运镜（越简单越稳定）
